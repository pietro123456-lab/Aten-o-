# ATENÇÃO — Jogos de foco

Jogo educativo e recreativo com atividades rápidas de atenção, concentração, memória e percepção visual.

## Como jogar
1. Abra o arquivo `index.html` no navegador ou publique o repositório com GitHub Pages.
2. Escolha uma atividade no menu.
3. Leia a instrução de cada rodada e responda.
4. Acompanhe pontos, nível e recorde.

## Atividades
- **Caça-figuras:** encontre o símbolo solicitado entre vários distratores.
- **Intruso visual:** identifique o elemento diferente.
- **Memória relâmpago:** observe e reproduza uma sequência.
- **Foco nas regras:** selecione os elementos que correspondem à regra apresentada.

## Observação importante
Este jogo é um recurso lúdico de apoio para atividades educativas ou sessões acompanhadas por um profissional. Não é teste psicológico, instrumento diagnóstico ou substituto de avaliação profissional.

O projeto funciona em um único arquivo HTML, sem dependências externas. O recorde fica salvo localmente no navegador usado.
